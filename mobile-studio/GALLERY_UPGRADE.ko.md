# 생성 화면·결과함 개선

- 네 가지 구성: 텍스트 → 이미지, 이미지 → 이미지, 텍스트 → 비디오, 이미지 → 비디오.
- 이미지 → 이미지는 참고 사진을 VAE/ReferenceLatent에 연결해 편집. 기존 사진 분석 기록은 결과함에 보존.
- 설치된 호환 모델만 선택: FLUX.2 Klein 4B, 4B FP8, Base 4B, Base 9B FP8. Base는 20단계, 일반 Klein은 4단계. 각 모델의 대응 텍스트 인코더를 사용. 영상은 현재 호환 그래프가 검증된 LTX 2.5 한 가지를 표시. 다른 모델은 임의로 다운로드하거나 호환되지 않는 그래프에 연결하지 않음.
- 완료·오류의 읽지 않은 알림을 상단·결과함·진행 중 배지에 표시. 알림 목록과 모두 읽음 제공. 지원 환경에서는 앱 아이콘 배지도 요청. 앱이 열린 동안 주기적 조회로 갱신하며 백그라운드 푸시는 추가하지 않음.
- 결과 다중 선택, 전체 선택, 다운로드, 사진 앱 저장용 파일 공유. 파일은 선택 시 미리 준비하며 사용자의 버튼 클릭에서 직접 공유창을 열어 사용자 활성화를 유지.
- iPhone 사진 라이브러리에 무인 직접 기록하는 권한은 웹앱에 없음. iPhone 공유창에서 사진/비디오 저장을 확인해야 함. 지원하지 않는 환경은 다운로드로 대체. 최대 20개·200MB씩 공유 준비하며 iPhone 실기기 저장은 별도 확인 필요.
- 삭제는 휴지통 이동. 결과 파일·ComfyUI 원본을 물리적으로 지우지 않으며, 휴지통 결과의 다운로드는 차단. 복원 가능. 생성 중 작업은 삭제하지 않음.
- 이미지/비디오 탭 시 전체화면 레이어. 닫기, Escape, 이전/다음, 비디오 재생 컨트롤 제공. 닫을 때 재생 중단·미디어 해제.

## 검증

- 기존 안전 검사와 새 모델·편집 그래프 검사 총 13개 통과.
- 운영 데이터와 분리한 DB/결과 복사본에서 일괄 삭제·복원·중간 유효성 실패의 원자성·CSRF·삭제 결과 접근 차단 검사 통과.
- 브라우저에서 네 가지 메뉴·FLUX 모델 4개·참고 사진 입력 확인.
- 테스트 상태 전환으로 완료 배지 1개, 오류 배지 1개와 상단 합계 2개 확인.
- 이미지 전체화면 열기·닫기, 비디오 레이어의 2초 실제 재생 종료 확인.
- 선택 파일의 공유 준비 버튼과 휴지통 이동·복원 화면 확인.
- 초기 파일은 `data/before-gallery-upgrade`에 보존.

현재 생성 작업을 취소하지 않고, 앱의 다음 작업을 보존한 채 전환 시점을 기다리는 배포 절차를 사용함. 기존 A/B 워크플로우는 변경하지 않음.

웹/API는 별도 로컬 8799에서 운영 DB를 사용하며 직접 GPU 작업을 실행하지 않음. 비공개 HTTPS의 대상은 이 웹 서버임. 기존 8787 작업자는 현재 생성·정리까지 계속 실행. 별도 배포 프로세스가 다음 작업을 보존하고 현재 작업 종료를 15초간 확인한 뒤 앱 작업자만 교체. 새 작업자 준비 마커가 없을 때 웹 API의 새 요청도 같은 대기 상태로 보존하며 이전 작업자가 새 이미지 편집 모드를 잘못 실행하지 못하게 함. 새 작업자 기동 후 대기 요청을 이어서 실행. start.ps1은 웹과 작업자를 함께 기동하도록 업데이트.

공유 API 근거: [MDN Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Share_API), [Navigator.share](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share). 저장 대상과 마지막 저장 확인은 기기의 공유창에서 결정됨.
