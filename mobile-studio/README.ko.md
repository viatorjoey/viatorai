# AI Creator Studio 모바일 PWA

Windows 로컬 웹 주소: http://localhost:8799 (기존 8787은 생성 작업자 겸 로컬 접속용)

연결 완료된 비공개 원격 주소: https://studio.example.invalid/ (Tailscale 연결 필요). HTTPS와 연결번호 인증, 보호된 API, 영상 범위 다운로드는 실제 검증했습니다. iPhone 실기기 확인은 남아 있습니다.

이 앱은 Windows의 ComfyUI(127.0.0.1:8188), Ollama(127.0.0.1:11434), Docker 컨테이너 `n8n`을 사용합니다. 외부 서버에 사진을 보내지 않습니다. 사이트 호스팅 서비스에 배포하지 않고 GPU가 있는 PC에서 실행합니다.

## 시작

PowerShell에서 `mobile-studio/start.ps1` 실행. Node.js 22 이상, 실행 중인 n8n/ComfyUI/Ollama가 필요합니다. 창을 숨겨 앱을 시작하며 http://localhost:8787 에서 접속합니다. Windows 재부팅 뒤에는 다시 실행해야 합니다. 자동 시작 등록은 아직 하지 않았습니다.

`start.ps1`은 이 앱 전용 CLI 호환성 파일을 컨테이너 `/tmp/ai-creator-mobile-preload.cjs`에 복사합니다. 설치된 n8n 코드를 수정하지 않습니다. 현재 n8n CLI는 Data Table 모듈을 초기화하지 않아, 이 앱의 짧은 CLI 실행 프로세스에서만 해당 모듈을 초기화합니다. 기존 n8n 서비스 프로세스나 환경 변수에는 적용하지 않습니다. CLI 작업 broker는 별도 5681 포트를 사용합니다.

## 기능

- 글 → 이미지: 설치된 FLUX.2 Klein 4B. 설명 충실도 1에서는 부정 설명의 영향이 약할 수 있습니다.
- 사진 → 설명: Ollama Qwen 3.5 9B의 한국어 설명과 영어 프롬프트. 응답 후 `keep_alive=0`과 `/api/ps`로 언로드 확인.
- 글 → 영상 / 사진 → 영상: 기존 B의 LTX 2.5 그래프를 별도 복사하여 사용. 사용자 장면을 직접 입력하고 선택적 프롬프트 보정 모델은 사용하지 않습니다. 24fps, H.264 MP4, 정확한 2/4/6/10초.
- 세로/가로/정사각형, 가벼운/균형/선명한 화질. 첫 영상은 2~4초·가벼운 화질을 권장합니다. 선명한 화질은 세로/가로 긴 변 1280, 이미지 긴 변 1024입니다. 모든 화질/길이 조합을 실제 검증한 것은 아닙니다.
- 결과함, 다운로드, iPhone 재생용 HTTP Range, 같은 설정 불러오기, 사진 설명 복사.
- JPG/PNG/WebP 20MB까지. HEIC는 JPEG로 변환해야 합니다. 완료 결과는 앱의 `data/results`에 별도 보존합니다. 기존 Drive 결과함으로 자동 업로드하지 않습니다.

## 기존 자동화와 충돌 방지

새 비활성 워크플로우 `OUEvnzeelRd84Sr8`을 작업마다 CLI로 실행합니다. 웹훅이나 스케줄은 활성화하지 않습니다. 기존 A/B의 Data Table `gd2WF5s9jDTeftKt`의 id=1, busy=false 조건으로 GPU를 획득하고 n8n 실행 ID를 owner로 기록합니다. 다른 작업이 소유하고 있으면 다음 주기에 다시 확인합니다.

생성 전 ComfyUI 큐가 비어 있는지 확인합니다. POST 제출은 한 번만 수행하고 prompt ID를 즉시 SQLite에 보존합니다. 정확한 prompt의 완료 성공과 자기 이름의 결과 파일을 확인합니다. 파일 바이트 형식·크기·SHA-256 검증 후 저장하고, 빈 큐를 다시 확인하여 `/free`를 호출합니다. PyTorch 예약 메모리 128MiB 이하·할당 16MiB 이하를 두 번 확인한 후에만 소유자 조건으로 잠금을 해제합니다. OS·드라이버 VRAM은 남을 수 있습니다.

상태 불명, 생성 오류, 저장/정리 실패 시 잠금을 유지하고 다음 모바일 작업을 차단합니다. 이는 기존 A/B도 대기하게 할 수 있는 안전 동작입니다. 오류를 무시하고 busy=false로 바꾸지 마세요. 큐 삭제·프로세스 종료·모델 삭제·자동 중복 제출은 하지 않습니다. 수동 ComfyUI 작업은 이 공용 잠금을 따르지 않을 수 있어 실행 중 별도 제출은 피하세요. 큐가 변하면 앱은 언로드를 중단합니다.

상태 조회나 마무리만 실패한 작업은 복구용 비활성 워크플로우 `2Fn3if59BIQZyrVf`로 원래 소유권과 생성 번호를 확인하고 추적을 재개할 수 있습니다. 데스크톱의 로컬 전용 `POST /api/reconcile/{jobId}`가 이를 실행합니다. 새 생성을 제출하지 않고 같은 prompt를 조회합니다. 정확한 성공 이력과 저장 파일 체크섬을 확인한 뒤에만 정리·잠금 해제를 합니다. 서버 재시작 후 진행 중이던 작업은 확인 필요로 전환하고 자동 재제출하지 않습니다.

## 원격 접속 및 iPhone 설치

Tailscale을 Windows와 iPhone에 설치하고 같은 계정으로 로그인합니다. Windows의 `connect-tailscale.ps1`은 기존 Serve 경로가 없을 때에만 이 앱의 8787을 tailnet 전용 HTTPS로 연결합니다. 계정 소유자의 HTTPS 활성화 절차가 필요할 수 있습니다. 기존 경로가 있으면 중단하여 검토하도록 했습니다. Funnel은 사용하지 않습니다.

표시된 HTTPS 주소를 iPhone Safari에서 열고, 데스크톱 앱의 연결 설정에 표시된 8자리 번호를 입력합니다. 번호는 서버를 시작할 때 바뀌며 로그나 저장소에 쓰지 않습니다. 세션은 HttpOnly·SameSite 쿠키이며 HTTPS에서는 Secure입니다. 번호 입력은 제한되어 있습니다. Tailscale 계정의 기기·접근 정책도 관리하세요.

Safari 공유 → 홈 화면에 추가. 앱 껍데기만 오프라인 캐시하고 사진·결과·API는 캐시하지 않습니다. 오프라인에서는 새 생성이나 결과 조회를 할 수 없습니다. 집 밖에서도 PC는 켜져 있고 절전 상태가 아니어야 합니다. iPhone 실기기 테스트는 사용자의 연결 후 필요합니다.

관리 포트 5678(n8n), 8188(ComfyUI), 11434(Ollama), 8788(내부 작업 브리지)은 인터넷에 공개하지 않습니다. 앱·브리지 서버도 127.0.0.1에만 바인딩합니다. 8788은 Tailscale 프록시에 연결하지 마세요. 내부 브리지는 로컬 Docker와 신뢰하는 Windows 환경에서만 사용하며, 게이트가 열린 해당 작업 ID만 한 번 실행하도록 제한합니다. PC의 다른 관리자/로컬 프로세스에 대한 보안 경계는 아닙니다.

## 검증
