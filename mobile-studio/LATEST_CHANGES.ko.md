# VIATOR AI STUDIO 변경 확인

- 생성 상단 소개 문구 제거, 빨간 하트와 VIATOR AI STUDIO 이름 적용. PWA safe-area-inset-top 적용. iPhone 실기기 설치 상태는 미검증.
- 메뉴 생성/진행/완료/설정, 진행 프롬프트 65자 요약 및 작업 종류, 예상 진행률과 초 단위 경과시간. 진행률은 시간 기반 추정이며 실제 샘플링 진행률이 아님.
- 결과 영상은 메타데이터 로드 후 0.1초 프레임을 표시. 선택 오른쪽 위 배치, 생성시간 표시. 이전 작업은 submissionIntent~updated 시간 기준.
- 5종 해상도: 512x288, 768x432, 1024x576, 1280x720, 1536x864. 세로는 축 반전. 영상 내부 연산은 엔진 배수 제약으로 올림하고 최종 결과는 선택 해상도로 조정.
- GPU 사용률/VRAM은 nvidia-smi 실측. 점검 시 GPU 100%, VRAM 15.1/16GB. ComfyUI HTTP 응답 지연 상태에서도 GPU 측정 표시.
- 수동 비우기는 인증 후 큐에 접수, 기존 공용 GPU 잠금을 획득한 워커에서 빈 ComfyUI 큐와 LLM 미사용을 확인한 뒤 처리. 실행 중 취소 없음.
- 받아쓰기 버튼 Web Speech API, 미지원 시 iPhone 키보드 마이크 안내. 실제 마이크 입력과 iPhone 실기기 미검증.
- 설치 qwen3.5:9b 모델 확인. 새 작업 enhance=true일 때 공용 GPU 잠금 아래 ComfyUI 캐시 해제 → Qwen JSON 보정 → keep_alive=0 및 언로드 확인 → 생성. 원문 보존, 결과에서 보정 내용 열람. 기존 작업 설정 미변경.
- Z-Image 설명 충실도 비활성화와 cfg=1 하드코딩 수정. 슬라이더 1~3 값이 KSampler cfg에 전달되고 1 초과 시 negative CLIPTextEncode 사용. 기본값 1 유지. 높은 CFG의 실제 결과 품질 비교는 미검증.

검증: 단위/그래프/안전 테스트 21개 통과. 별도 임시 DB/테스트 서버에서 인증, enhance와 해상도 저장, 비우기 큐 접수 및 중복 방지 HTTP 검증 통과. 브라우저에서 슬라이더 2.5 표시 확인. 기존 영상이 실행 중이므로 새 GPU 생성 및 LLM 보정, VRAM 비우기는 실행하지 않음.

배포: UI와 API 접수는 localhost:8799에 반영. 기존 8787 생성 워커는 중단하지 않음. 기존 배포 대기 프로세스가 현재 작업 종료 후 최신 워커를 로드하며, 그때까지 새 요청은 upgrade_wait로 보존. 원격 주소는 https://studio.example.invalid/ 유지. 기존 n8n A/B 워크플로우 미변경.

## 입력 UI 및 제어 추가
- 프롬프트 우측 하단 SVG 마이크, LLM 수정 옵션, 예시 버튼 제거, 기본 네거티브, 상세옵션/시드 명칭 적용.
- 이미지 PNG 무손실, 영상 H.264 CRF 24/18/12 실제 SaveVideo 인코딩 옵션 연결.
- 작업중단은 준비/확인 토큰이 해당 로그인 세션과 대상 job/prompt에 묶이며, 실행 직전 상태 재확인 후 로컬 ComfyUI의 검증된 /api/jobs/{job_id}/cancel 원자적 대상 취소 사용. 다른 자동화/대기열 삭제 없음. 중단 후 GPU 잠금은 자동 해제하지 않음.
- 서버리셋은 API_ONLY 웹앱 서버만 재시작. 생성 워커, ComfyUI, n8n 유지. 실제 중단/리셋 버튼 실행은 하지 않음.
- 테스트 22개 통과, 격리 HTTP에서 잘못된 확인 토큰 거부 및 테스트 서버 실제 제어 차단 확인. 현재 생성 작업과 A/B 워크플로우 유지.

## 리셋 복구 및 작업중단 수정
- 리셋의 자식 PowerShell 재기동 의존성을 제거. 웹 서버 프로세스는 유지하고 HTTP 리스너를 다시 열며 클라이언트는 인증 API 복구를 확인한 뒤 새로고침.
- 실제 Tailscale HTTPS 주소에서 리셋/페이지/인증 세션 복구를 두 차례 확인. 생성 워커 PID 58176 유지, 실행 작업 식별자 및 상태 유지 검증.
- 작업중단 확인 시 앱 대기 작업을 SQLite 트랜잭션으로 cancelled 처리. upgrade_wait 작업도 JSON state queued 대상에 포함되어 즉시 취소되며 자동 재실행되지 않음. 확인 당시 목록만 처리. 실행 작업은 별도의 대상 지정 중단 요청. A/B 자동화 미변경.
- 격리 HTTP 테스트에서 대기 작업 2개 즉시 취소 및 취소 상태 저장 검증. 실제 사용자의 대기/실행 작업은 테스트로 취소하지 않음. 단위 테스트 22개 통과.

## 완료 목록과 즐겨찾기
- 진행/완료/설정의 상단 장식 제목과 설명 제거.
- 완료 목록은 이미지/영상 첫 프레임의 작은 썸네일 및 옆 선택/삭제/공유/하트 버튼으로 구성. 썸네일 클릭 전체화면 유지.
- favorite boolean을 완료 작업에 서버 저장. 휴지통 옆 즐겨찾기 필터, 해제 및 재접속 저장 확인. 즐겨찾기/삭제가 이전 작업 생성시간을 바꾸지 않도록 완료 시각 보존.
- 개별 공유는 파일 준비 후 두 번째 사용자 클릭으로 Web Share 실행. 미지원 브라우저는 다운로드. 실제 외부 공유는 테스트하지 않음.
- 합성 풍경 이미지/영상만 사용한 별도 8809 QA에서 썸네일, 하트 저장, 새로고침 후 유지, 필터, 공유 준비 검증. 사용자 실제 결과 미수정. 격리 HTTP 즐겨찾기 추가/해제 및 완료시각 보존 통과. 기존 단위 테스트 22개 통과.

## 15분 제한 및 미디어 선택 UX
- 진행 화면 각 실행 작업에 해당 작업만 중단하는 버튼. 전체 중단과 별도 범위 확인. 취소 요청 영속 테이블 및 엔진 재확인, 실제 중단 전 성공으로 처리하지 않음.
- 실제 실행 시작 기준 15분 초과 감시(10초 주기). 취소 후 미완성 항목은 목록에서 삭제 처리하며 완료 결과 접근도 차단. 복구용 기록/파일의 물리적 영구 삭제는 하지 않음.
- 기존 15분 초과 작업 1건의 ComfyUI 대기열 이탈 확인. 구형 워커의 사라진 기록 무한 대기를 최신 워커로 복구하고 기존 n8n 복구 흐름으로 VRAM 정리. GPU 공용 잠금 busy=0, owner 빈 값 확인. 취소 완료가 오류로 뒤집히던 종료 처리도 수정. A/B와 ComfyUI 재시작 없음.
- 영상은 기존 ComfyUI Python의 PyAV로 CPU JPEG 썸네일 생성. 실제 합성 MP4→JPEG HTTP 테스트 통과.
- 전체 선택은 오른쪽, 선택 모드에서만 각 항목 오른쪽 체크 표시. 하단 메뉴 저장/다운로드/삭제/닫기. 선택 닫기 시 체크와 메뉴 숨김 확인.
- 상세 버튼 제거. 썸네일 클릭은 전체화면과 닫기, 프롬프트 텍스트 클릭은 전체 프롬프트/설정 팝업과 닫기. 브라우저 확인.
- 화질 옵션 제거, 새 작업 최고 저장 품질 고정(PNG 무손실/H.264 CRF12). 이미지/영상 생성 버튼 44px 높이, 14px 글자, 최대폭360px.
