# 프롬프트 보정 재사용 및 CPU 처리

- 원문·네거티브·생성 모드·모델이 같으면 참조 이미지를 바꿔도 영어 보정문을 재사용합니다. 시드와 해상도 등 생성 옵션 변경도 보정 재생성을 일으키지 않습니다.
- 새로운 보정은 `/api/refinements`에서 기존 CPU 전용 Ollama로 실행합니다. 대기 GPU 작업을 생성하지 않고, 완료된 보정문만 저장합니다.
- CPU 채팅과 동일한 메모리 슬롯을 공유하고 Qwen 추정 9GiB 외에 시스템 RAM 10GiB를 확보합니다. 완료·오류 모두 모델 언로드를 검증합니다.
- 이전 보정 결과가 같은 원문·네거티브·모드·모델로 저장되어 있으면 서버에서도 재사용합니다. 명시적인 다시 생성은 새 결과를 만듭니다.

검증: 자동 테스트 52개 및 격리 HTTP 계약 검증 통과. 실제 영상 작업 1개가 진행 중인 상태에서 보정 성공, CPU Ollama 관측 VRAM 0바이트 및 모델 해제 확인. 짧은 보정문 지침 적용 후 별도 짧은 장면 신규 보정 약 29.8초. 입력 길이와 CPU 부하에 따라 시간은 달라집니다. 실제 브라우저에서 동일 입력 보정 결과가 진행 화면 이동 없이 표시되는 것을 확인했습니다.
