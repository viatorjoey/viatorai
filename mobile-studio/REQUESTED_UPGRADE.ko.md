# 설정·결과함·채팅·VRAM 개선

2026-10-16 (America/New_York). 실행 주소는 기존 localhost:8799 및 Tailscale HTTPS 주소를 유지합니다.

## 반영한 기능

- 설정의 서버리셋을 **콤피UI 재시작**으로 교체했습니다. 공용 GPU 소유권, 확인 당시의 작업 목록, ComfyUI 8188 리스너 PID와 정확한 Python 경로를 확인한 뒤 해당 엔진과 venv 런처만 강제 종료합니다. 기존 인수와 작업 디렉터리로 숨김 실행하고 **새 PID의 API 응답과 빈 큐**를 확인해야 성공입니다. 실패·시간 초과도 영속 알림에 기록합니다. 웹앱·Comfy Desktop·n8n 전체를 재시작하지 않습니다. 다른 자동화의 GPU 소유권 또는 앱 외부 큐가 있으면 거부합니다.
- VRAM 비우기·작업중단·콤피UI 재시작은 같은 폭·높이·검정 배경·주황 글씨와 테두리입니다. 누름/포커스/처리 중에는 주황 배경·검정 글씨입니다. 상태 제목은 **비아토르 AI 서버 상태**입니다. 작업 확인창은 동일 크기의 **취소 / 실행**입니다.
- 전체화면 하단은 **이전 / 저장 / 닫기 / 다음**입니다. 좌우 터치 슬라이드와 방향키로 결과를 이동합니다. 영상 조작바, 세로 스크롤, 핀치 확대를 구분합니다.
- 상세 프롬프트의 **같은 설정으로 다시 만들기**를 큰 주황 버튼으로 바꿨습니다. 원래 생성에 사용한 실제 프롬프트·네거티브·모델·시드·해상도·길이·입력 이미지를 서버에서 복사해 바로 접수하며, 보정 LLM을 다시 실행하지 않습니다. 닫기는 우하단입니다.
- 이미지/영상 모두 하트 옆 **🔄 재제작**이 있습니다. 이미지는 별도의 **빨간 ▶ 영상 만들기**가 있으며, 생성 이미지를 입력 이미지로 등록하고 기존 프롬프트와 공통 설정을 보존해 설치된 LTX 영상 모델로 바로 접수합니다.
- 완료 카드에서 **왼쪽 슬라이드 = 즐겨찾기**, **오른쪽 슬라이드 = 휴지통**입니다. 휴지통에서는 복원할 수 있습니다.
- 하단 가운데 **채팅**을 추가했습니다. 설치된 **Qwen 3.5 9B / GPT-OSS 20B** 선택, 새 대화, 제목 검색, 이름 변경, 삭제, 다시 열기, 답변 복사, 이미지 첨부·미리보기·보관 이미지 표시, 받아쓰기를 지원합니다. 이미지가 있는 대화는 시각 입력을 지원하는 Qwen을 사용합니다. 서버에 내역을 저장하며 마지막으로 실제로 연 뒤 5일이 지난 대화는 정리합니다. 백그라운드 폴링은 보관 기한을 연장하지 않으며 진행 중인 답변은 보호합니다.
- iPhone 홈 화면 앱의 **완료·오류 알림 켜기**를 추가했습니다. 서버 Web Push, 서비스워커 알림 표시, 앱 배지 갱신, 클릭 시 진행/완료 페이지 연결, 읽음 처리를 구현했습니다. 알림에는 개인 프롬프트나 이미지를 넣지 않습니다.

## 16GB VRAM 처리 정책

채팅·사진 분석·프롬프트 보정·이미지/영상 생성은 기존 n8n 공용 GPU 잠금을 공유합니다. LLM과 ComfyUI 생성이 동시에 실행되지 않습니다.

LLM 요청은 `keep_alive=0`, 제한된 컨텍스트를 사용합니다. 성공과 예외 모두 해당 모델에 명시적 언로드를 보내고 `/api/ps`에서 사라졌는지 확인합니다. 추가로 `nvidia-smi` 사용량이 LLM 시작 전 기준 +512MiB 이내로 두 번 연속 돌아오는지 확인합니다. 확인 전에는 다음 모델을 시작하지 않습니다.

생성용 텍스트 인코더는 CPU에 배치해 대형 Gemma/Qwen 인코더가 확산 모델과 16GB VRAM을 경쟁하지 않도록 했습니다. CPU 인코딩은 시간이 더 걸릴 수 있습니다. 설치된 모델이나 사용자 해상도를 임의로 다른 것으로 바꾸지는 않습니다. 생성이 끝나면 파일을 검증·저장한 뒤 ComfyUI 모델/실행 캐시 해제와 낮은 PyTorch 할당량을 확인하고 공용 잠금을 반환합니다.

**GPU가 실행 중일 때의 비우기는 즉시 강제 해제가 아닙니다.** 설치된 ComfyUI `/free`는 실행이 끝나거나 멈춘 뒤 처리됩니다. 앱은 접수·대기·성공·실패를 표시합니다. 멈춘 생성을 끝내려면 작업중단을, 엔진 강제 종료가 필요하면 대상 확인창을 거쳐 콤피UI 재시작을 사용합니다. 비우기 버튼으로 다른 작업을 몰래 취소하지 않습니다.

## 확인한 범위

- 단위/그래프/수명주기/제스처 테스트 **44개 통과**.
- 격리 HTTP: 인증·취소 범위·보정문 재사용·즐겨찾기/휴지통 보존·채팅 CRUD·중복 전송 방지·이미지 접근 권한·삭제 후 이미지 접근 차단·두 모델 목록·실제 프롬프트/설정 재제작·이미지→영상 접수·푸시 주소 검증 통과.
- 실제 Qwen 및 GPT-OSS 채팅 답변 저장과 각 응답 후 `/api/ps` 빈 목록 확인.
- 실제 VRAM 비우기 완료. 점검 중 표시된 사용량 **14.3GB → 2.3GB**. 상태 API에는 최대 4초 측정 캐시가 있으므로 작업별 반환 확인은 별도의 직접 GPU 측정을 사용합니다.
- 실제 ComfyUI 강제 재시작: 엔진 PID **25976 → 55412**, 새 엔진 응답과 빈 대기열 확인. 같은 PID 유지·실행 실패·외부 작업·확인 후 대상 변경은 별도 실패 테스트로 검증.
- 기존 Tailscale HTTPS: 새 JS 모듈 제공, 인증 API 세션 유지, 비인증 채팅 접근 차단 확인.
- 브라우저: 가운데 채팅과 두 모델 선택, 실제 Qwen 응답, 완료의 재제작/영상 버튼, 전체화면 버튼 순서와 다음 이동, 상세 프롬프트 하단 버튼 확인.

**실제 연속 영상 2건도 통과했습니다.** 두 결과 모두 512×288, 24fps, 48프레임, 정확히 2초인 MP4로 확인했습니다. 작업 시간은 각각 208초 / 180초였습니다. 각 작업의 보정 LLM 메모리는 2,538→2,548MiB 및 2,438→2,439MiB로 반환됐고, 완료 후 PyTorch 예약량은 각각 32MiB, 할당량은 약 8.1MiB였습니다. 최종 VRAM은 2.3GB, ComfyUI 실행/대기 0개, Ollama 상주 모델 0개였습니다. 검증 조회 중 웹앱 교체로 연결이 한 차례 끊겼지만, 같은 두 작업 ID로 조회를 재개했으며 재제출하지 않았습니다. 기계 판독용 기록은 `data/upgrade-live-results.json` 및 `data/upgrade-video-resume-results.json`입니다.

## 기기에서 남은 확인

iPhone 홈 화면 웹앱에서 알림 권한을 직접 허용해야 합니다. 실제 iPhone 잠금/앱 종료 상태의 푸시 수신과 빨간 아이콘 배지, 터치 제스처, 마이크 입력은 이 PC에서 실기기로 확인할 수 없습니다. 브라우저 음성 인식 미지원 시 iPhone 키보드 마이크를 사용합니다. iOS 홈 화면 알림/배지 조건은 [WebKit 안내](https://webkit.org/blog/13878/)를 따릅니다.

기존 A/B 워크플로우·모델 파일·Docker 구성·포트·Tailscale 공개 범위는 유지했습니다. 원격 MCP 상태 조회가 429를 반환해, 이미 확인된 이 PC의 로컬 API와 기존 CLI로 검사했습니다. `sources/`는 수정하지 않았습니다.
- 마지막 모바일 화면 검수에서 채팅 입력창을 화면 높이에 맞추고 하단 메뉴 위에 배치했습니다. 내역 패널은 대화 영역 위에 겹쳐 열려 입력창을 밀어내지 않습니다.
